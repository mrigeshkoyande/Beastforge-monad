# MONAD HUNT ENGINEERING RULES

1. Do not rewrite working code unnecessarily.
2. Do not introduce dependencies without justification.
3. Do not build features outside the current phase.
4. Do not use fake blockchain confirmations.
5. Do not expose private keys.
6. Do not trust the frontend for financial settlement.
7. Do not use block.timestamp as secure randomness.
8. Do not transfer player Beast NFTs as battle rewards.
9. Do not implement real-money prediction/betting.
10. Do not make the game dependent on external AI APIs.
11. Demo mode must always remain functional.
12. Monad Testnet is the target blockchain.
13. Keep blockchain logic isolated from game rendering.
14. Keep Phaser game logic independent from React UI.
15. Every contract change requires tests.
16. Every major frontend change must pass typecheck and build.
17. Prefer simple, auditable implementations over complex architecture.
18. Optimize for a polished hackathon demo.
