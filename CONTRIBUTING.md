# Contributing to MONAD HUNT — CITY LEAGUE

Thank you for your interest in contributing to **MONAD HUNT: CITY LEAGUE**! 

We welcome contributions from developers, game designers, Solidity engineers, and artists.

---

## Code of Conduct

Please be respectful and collaborative. We are committed to providing a friendly, safe, and welcoming environment for all contributors.

---

## Development Workflow

1. **Fork & Clone**
   ```bash
   git clone https://github.com/<your-username>/Beastforge-monad.git
   cd Beastforge-monad/apps/web
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Create a Feature Branch**
   ```bash
   git checkout -b feat/your-feature-name
   ```

4. **Run Locally**
   ```bash
   npm run dev
   ```

5. **Typecheck & Build**
   Ensure all changes pass TypeScript checks and build without errors:
   ```bash
   npm run typecheck
   npm run build
   ```

6. **Submit a Pull Request**
   Push your branch and open a PR against the `main` branch with a clear summary of changes.

---

## Engineering Rules & Standards

- **No Rewrite of Working Code**: Enhance and extend rather than rewriting stable components.
- **Isolate Logic**: Keep smart contract calls, Web Audio API synthesis, and React components decoupled.
- **Never Commit Secrets**: Do not commit `.env.local`, API keys, or private keys.
- **Clean UI**: Adhere to the dark cyberpunk esports visual system with high contrast and subtle animations.
